**Логика:**
1. При переводе Предложения в статус "На валидации" вызывается API route

## Известные ограничения

1. **Агент не меняет статус** — это осознанное архитектурное решение. Агент пишет только в `verdict_*`, финальное решение принимает человек.

2. **Реестр документов должен быть актуален** — агент читает `docs/` на момент вызова. Если документы устареют, вердикт будет некорректным. Это операционное требование, не технический баг.

3. **Prompt caching работает только при повторных вызовах** — первый вызов агента будет медленнее и дороже. При 3–5 вызовах в неделю экономия составит ~80% токенов.
