Откройте: https://supabase.com/dashboard/project/rhkiydcqbzmfuayygzbe/sql/new

```

```

Или воспользуйтесь подробной инструкцией в `MIGRATION_GUIDE.md`

### 2. Проверить работу

После применения миграции:

1. Откройте http://localhost:3000/proposals
2. Создайте тестовое Предложение
3. Переведите его в статус "На валидации"
4. Дождитесь вердикта агента (~5-10 секунд)
5. Проверьте, что отображается вердикт с обоснованием
6. Нажмите "Оформить как Решение"
7. Проверьте, что запись появилась в разделе "Решения"

## Если что-то не работает

### Агент возвращает ошибку

Проверьте в `.env.local`:
- `ANTHROPIC_API_KEY` указан корректно
- `ANTHROPIC_BASE_URL=https://ai.starimg.r` указан

### Страница /proposals не загружается

1. Убедитесь, что миграция применена: выполните в Supabase SQL Editor:
   ```sql
   select count(*) from public.proposals;
   ```
   Должно вернуться `0` без ошибки.

2. Проверьте, что Supabase credentials в `.env.local`:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`

### Dev-сервер не запущен

```bash
npm run dev
```

Откроется на http://localhost:3000
